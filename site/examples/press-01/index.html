Press Quaternary is Bríd Halloran’s one-person type studio in Cork. Quaternary Grotesque has weight, width and optical size axes and Latin Extended. This page is set in Quaternary Grotesque, shown in Roboto Flex as a stand-in, with Source Serif 4 for the text.
